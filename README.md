# Guardrail Decision Format (GDF)

**An open, vendor-neutral standard for auditable, policy-governed AI decisions in regulated and enterprise environments.**

GDF defines a compliance-grade, machine- and human-readable format for documenting how AI systems access data, take actions, and are governed by policy.

It is designed to serve as:
- A **compliance artifact** for auditors and regulators
- An **interoperability layer** across AI platforms and policy engines
- A **governance control plane** for enterprise and regulated AI systems
